# Squad Busters Archive — starter

Site estático responsivo para uma wiki/arquivo comunitário não oficial.

## Editar o catálogo
Abra `data/assets.json` e adicione entradas no array `items`.
Campos:
- `id`: identificador único
- `name`: título da entrada
- `category`: Personagens, Cosméticos, Interface, Mídia ou História
- `description`: descrição curta
- `icon`: símbolo provisório
- `source_url`: fonte pública para consulta

## Imagens
Antes de publicar cópias de assets da Supercell, confira a Política de Conteúdo para Fãs e obtenha autorização quando necessário. O starter não redistribui imagens protegidas: ele começa com cartões tipográficos e links de fontes.

## Publicação
Pode ser hospedado como site estático. Para GitHub Pages, crie um repositório com nome neutro, envie os arquivos e ative Pages nas configurações do repositório. Não use nome de domínio com marcas da Supercell ou de Squad Busters sem autorização escrita.
